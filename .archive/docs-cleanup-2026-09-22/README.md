# Documentation Cleanup Archive

This archive preserves the original bytes of retired site tooling, optional root documentation and completed plans.
It is historical evidence, not active agent guidance or a source of current release/version state.

The [manifest](manifest.json) records original paths, archived paths and SHA-256 hashes at retirement.
Relative links in archived files retain their historical meaning and may refer to the old repository layout.
The active tooling is tested to exclude these archived skill, instruction and prompt files from discovery.

Current documentation lives at <https://apexops.pro/> and in <https://github.com/jonathan-vella/apex-docs>.
Runtime guidance, templates, version metadata, legal files and unresolved implementation plans remain in APEX.
The removed Sensei maintenance workflow remains available through Git history; no branch or ruleset was deleted.
